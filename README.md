# Lexora Service

Android-проект Lexora Service — система управления сервисным обслуживанием в составе семейства Lexora.

## Версия
0.28.0 / versionCode 28

## Реализовано
- многомодульный Android-каркас;
- единая дизайн-система Lexora (foundation);
- активная организация, RBAC и реестр модулей;
- подключаемые модули «Автомойка» и «Шиномонтаж» как изолированные feature-модули;
- Room database без destructive migration;
- offline sync state и базовый аудит;
- базовые сущности Organization, Client, Vehicle, ServiceObject, Equipment, Branch, Employee;
- модуль «Клиенты»: поиск, создание, редактирование, реквизиты, архив/восстановление и защита от очевидных дублей;
- модуль «Автомобили»: CRUD, поиск, привязка к клиенту, VIN/госномер, параметры автомобиля и сервисная история foundation;
- модуль «Объекты и оборудование»: клиент → объект → оборудование, поиск, CRUD, архив/восстановление, серийные/инвентарные номера и QR/штрихкод foundation;
- модуль «Филиалы и сотрудники»: филиальная структура, контакты и график филиала, сотрудники, должности, контакты, привязка к филиалу, деактивация/восстановление и аудит.

## Состояние сборки
Актуальный статус сборки фиксируется в `build-diagnostics/latest-summary.txt`. Успешная сборка заявляется только после фактического завершения `assembleDebug` с кодом успеха и получения APK.
