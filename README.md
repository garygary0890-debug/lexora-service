# Lexora Service

Android-проект Lexora Service — система управления сервисным обслуживанием в составе семейства Lexora.

## Версия
0.5.0 / versionCode 5

## Реализовано
- многомодульный Android-каркас;
- единая дизайн-система Lexora (foundation);
- активная организация, RBAC и реестр модулей;
- подключаемые модули «Автомойка» и «Шиномонтаж» как изолированные feature-модули;
- Room database schema v3 без destructive migration;
- offline sync state и базовый аудит;
- базовые сущности Organization, Client, Vehicle, Branch, Employee;
- модуль «Клиенты»: поиск, создание, редактирование, физ/юр лицо, реквизиты, адреса, защита от очевидных дублей, архив/восстановление;
- модуль «Автомобили»: CRUD-каркас, поиск, привязка к клиенту, VIN/госномер, марка/модель, год, кузов, цвет, пробег, архив/восстановление;
- фундамент общей сервисной истории автомобиля.
