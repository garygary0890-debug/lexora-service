## Блокеры текущего релиза

1. `build-diagnostics/latest-summary.txt` пока имеет статус `NO_BUILD_YET`.
2. Production signing configuration не должна хранить секреты в GitHub и пока не настроена.
3. Реальный серверный `SyncTransport` пока отсутствует; это не мешает локальному MVP, но серверную синхронизацию нельзя считать готовой.
4. Полноценный capture UI фотографий и графической подписи клиента ещё не реализован.
5. Клиентский кабинет и онлайн-запись остаются только интеграционной заготовкой по ТЗ.

Релиз не считается подтверждённым, пока обязательные build/test gates не закрыты фактическими результатами.
