# SRV-BUG — временное отключение авторизации для ручных тестов

Дата: 2026-10-06
Статус реализации: внесено в код
Статус проверки: сборка не выполнялась

## Требование

Временно отключить обязательный вход для ручных тестов Lexora Service.

## Реализация

В `BackendAuthActivity` добавлена отдельная кнопка:

`Войти без авторизации (ручные тесты)`

Режим:

- очищает локальную backend-сессию;
- не создает и не сохраняет серверные токены;
- открывает `MainActivity` с `globalOwner = true`;
- оставляет штатные способы входа по логину/паролю и через Lexora Admin без удаления.

## Ограничения

Это временный bypass только для ручной проверки UI/локального рабочего пространства. Перед приемкой авторизации, security-check и релизом режим должен быть удален или закрыт отдельным debug-only флагом.

## Затронутые файлы

- `app/src/main/java/com/lexora/service/BackendAuthActivity.kt`

## Проверка

Не выполнялась в этой сессии: нет подтвержденного локального запуска Gradle/Android сборки через подключенный терминал.
